# EMS员工管理系统开发总结
## 一、项目实现步骤
### 1. 项目初始化与环境搭建
（1）创建Spring Boot项目
通过阿里云骨架创建Maven项目，命名`demo-jsp-ems`，坐标可自定义（如`com.wyh`/`com.zfh`），选择JDK8，核心依赖勾选Spring Web；创建完成后启动项目测试，查看端口号（默认8080，也可配置为8088）是否被占用，同时查看默认前端页面。

（2）pom.xml核心依赖配置
添加JSP、JSTL、MyBatis、MySQL、Druid、Lombok、热部署等依赖，保证项目基础功能支撑：

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>2.3.12.RELEASE</version>
    <relativePath/>
</parent>
<dependencies>
    <!-- web核心 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <!-- jsp支持 -->
    <dependency>
        <groupId>org.apache.tomcat.embed</groupId>
        <artifactId>tomcat-embed-jasper</artifactId>
    </dependency>
    <!-- jstl标签 -->
    <dependency>
        <groupId>jstl</groupId>
        <artifactId>jstl</artifactId>
        <version>1.2</version>
    </dependency>
    <!-- mybatis -->
    <dependency>
        <groupId>org.mybatis.spring.boot</groupId>
        <artifactId>mybatis-spring-boot-starter</artifactId>
        <version>2.1.3</version>
    </dependency>
    <!-- mysql驱动 -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <scope>runtime</scope>
    </dependency>
    <!-- druid连接池 -->
    <dependency>
        <groupId>com.alibaba</groupId>
        <artifactId>druid</artifactId>
        <version>1.1.20</version>
    </dependency>
    <!-- lombok简化代码 -->
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>
    <!-- 热部署 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-devtools</artifactId>
        <scope>runtime</scope>
        <optional>true</optional>
    </dependency>
    <!-- 测试 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-test</artifactId>
        <scope>test</scope>
    </dependency>
</dependencies>
```

添加依赖后再次运行项目测试，确保依赖引入无异常。

### 2. 项目结构规划与目录配置

（1）包结构规范

在指定根目录）下添加项目包，严格按照 JavaEE 分层思想创建：

- `common`：公共常量
- `utils`：工具类
- `entity`：实体类
- `dao`：数据访问层接口
- `service`：业务层接口 + 实现
- `controller`：控制层
- `config`：配置类
- 资源目录：`resources/mapper`（MyBatis的xml映射文件）

（2）webapp 目录

在 main 目录下手动添加`webapp`目录，及`webapp`下的`WEB-INF`子目录；同时在 IDEA 中打开项目工作目录，点击编辑配置，选中当前所在模块，修改工作目录为项目根路径。

（3）视图配置

打开项目配置文件，配置 MVC 视图解析规则：

```properties
# jsp视图配置
spring.mvc.view.prefix=/WEB-INF/
spring.mvc.view.suffix=.jsp
```

### 4. 核心代码开发

（1）实体层开发

添加 Lombok 依赖后，创建`User`和`Emp`实体类，使用 Lombok 注解简化代码：

```java
// 用户实体
@Data
@NoArgsConstructor
@AllArgsConstructor
@Accessors(chain = true)
public class User implements Serializable {
    private String id;
    private String username;
    private String realname;
    private String password;
    private String gender;
}
// 员工实体
@Data
@NoArgsConstructor
@AllArgsConstructor
@Accessors(chain = true)
public class Emp {
    private String id;
    private String name;
    private Double salary;
    private Integer age;
}
```

（2）持久层（DAO/Mapper）开发

- 创建基础 CRUD 接口`BaseDao`，统一规范；
- 编写`UserDao`、`EmpDao`接口，继承基础接口；
- 编写 MyBatis 映射文件（`UserDaoMapper.xml`、`EmpDaoMapper.xml`），实现 SQL 语句；
- 启动类添加`@MapperScan("dao")`扫描 DAO 接口；
- 注意：多参数传递时需添加`@Param`注解（如分页查询的 start 和 size 参数），否则 MyBatis 无法识别参数名。

（3）业务层（Service）开发

- 编写`UserService`、`EmpService`业务接口；
- 编写实现类，添加`@Service`注解，注入 DAO 对象；
- 实现核心业务：用户注册、登录、员工增删改查；
- 生成 Service 测试类，进行单元测试，验证业务逻辑正确性（包括用户插入 / 登录查询、员工增删改查 / 分页查询 / 按 ID 查询 / 总记录数查询等场景）。

（4）控制层（Controller）开发

- 创建导航控制器（如`IndexController`）、用户控制器（`UserController`）、员工控制器（`EmpController`）、退出控制器；
- 实现页面跳转导航、接收请求参数、调用业务层、页面跳转 / 重定向、登录校验（Session 判断）等功能；
- 接收前端提交的数据，调用业务层完成数据处理；
- 退出登录功能需调用`session.invalidate()`销毁会话，并重定向到登录页。

（5）视图层（JSP）开发

- 在`webapp/WEB-INF`下创建页面目录，编写核心页面：
  - 首页：`index.jsp`（导航主页）
  - 用户模块：`user/login.jsp`、`user/regist.jsp`
  - 员工模块：`emp/main.jsp`、`emp/add.jsp`、`emp/edit.jsp`
- 先在 webapp 目录下添加`test.jsp`文件测试 JSP 基础功能，再将其复制到`WEB-INF`子目录下优化；
- 使用 JSTL+EL 实现数据渲染、表单提交、提示信息回显；
- 优化用户登录和注册 JSP 代码，提升用户体验；
- 修改 JSP 代码后无需关闭项目，直接刷新浏览器即可查看变化（依赖热部署配置）。

### 5. 功能测试

（1）单元测试

- 对 DAO 层（用户 / 员工的增删改查、分页查询、总记录数查询等）、Service 层接口进行单元测试；
- 重点测试：用户插入 / 登录查询、员工增删改查 / 分页查询 / 按 ID 查询 / 总记录数查询等场景；
- 注意 xml 文件配置正确性，确保参数绑定、SQL 执行无异常。

（2）前端页面测试

- 启动项目，访问`http://localhost:端口号/index`；
- 测试全流程：用户注册→登录→员工管理（增删改查）→退出登录；
- 验证页面跳转、数据提交、功能交互是否正常。

## 二、开发过程中碰到的问题及解决方案

### 问题 1：Spring Boot 不支持 JSP，访问 404

#### 现象

创建 JSP 页面后，浏览器访问报 404 错误。

#### 原因

Spring Boot 找不到 webapp 目录，未配置 JSP 依赖和视图解析。

#### 解决方案

1. 添加`tomcat-embed-jasper`和`jstl`依赖；
2. 在 main 目录下手动创建`webapp/WEB-INF`目录；
3. 配置`spring.mvc.view.prefix/suffix`；
4. IDEA 设置工作目录为项目根路径。

### 问题 2：MyBatis 参数绑定异常

#### 现象

登录查询报错：`Parameter 'username' not found`。

#### 原因

DAO 接口多参数时，MyBatis 默认无法识别参数名。

#### 解决方案

1. 参数添加`@Param("username")`注解；
2. 或使用`#{param1}`、`#{param2}`按位置取值。

### 问题 3：查询返回结果过多异常

#### 现象

登录时报`TooManyResultsException`，期望 1 条返回多条。

#### 原因

用户名重复，业务上用户名必须唯一。

#### 解决方案

删除数据库重复用户数据，后续添加用户名唯一性校验。

### 问题 4：退出登录功能失效

#### 现象

点击退出后，仍能直接访问员工管理页面。

#### 原因

未销毁 Session，登录状态保留。

#### 解决方案

控制器中调用`session.invalidate()`让会话失效，并重定向到登录页。
