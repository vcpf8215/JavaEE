# Lombok

Lombok是能输出注释，自动生成多种模版代码的第三方组件。比如对于实体类(entity)中`getter`、`setter`方法等。

## 构造

良好的Lombok组件的使用可以帮助开发人员快速、高效地完成开发。如下面的代码：

``` Java
// 不使用Lombok
public class Person {
    private String name;

    // 多态接口，描述具体的工具属性
    private Driveable driveable;

    // 出去逛具体的逛法调用
    public void hangOut() {
        driveable.drive();
    }
    
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public Driveable getDriveable() {
        return driveable;
    }

    public void setDriveable(Driveable driveable) {
        this.driveable = driveable;
    }
}
```

``` java
// 使用Lombok
@Data
@AllArgsConstructor
@NoArgsConstructor
@Accessors(chain = true)
public class Person {
    private String name;

    // 多态接口，描述具体的工具属性
    private Driveable driveable;

    // 出去逛具体的逛法调用
    public void hangOut() {
        driveable.drive();
    }
}
```

可以看到使用组件和不使用组件的差别还是很大的，恰当的使用这些组件可以帮助我们快速地开发。

那么上面的组件都有什么作用呢？

* `@Data` 这是快速生成`getter` 和`setter`的注解，省去了get和set的重复工作。同时`@Data` 也重写了`toString`和`HashMap`方法。

  * 当然还有单独的get和set注解`@Getter`，`@Setter`

* `@AllArgsConstructor`和`@NoArgsConstructor` 分别对应的是全参构造器和无参构造器。

* `@Accessors(chain = true)` 允许链式地调用get和set方法，让代码更加简洁。

  ``` java
  // 就是从这样
  User user = new User();
  user.setId(1L);    // 单独一行
  user.setName("小明"); // 再单独一行
  
  // 变成这样
  User user = new User().setId(1L).setName("小明");
  ```

## 日志

在真实的项目开发中，我们需要调试我们的代码，程序打印日志，通过日志信息判断程序是否正常运行，就像医生通过检查报告判断人的身体是否健康一样。那么这些所谓的”体检报告“从何而来呢？

`@Slf4j` 解决了这个问题。这个注解也是Lombok提供的注解，它的作用是代替之前学习过的`sout`输出。添加`@Slf4j`，可以通过`log`方法输出不同登记的日志信息，如：

``` java 
@BeforeEach
    public void init() {
        log.info("常规测试开始：");
    }
```

输出`info`等级的日志，运行结果如下：

``` java
20:45:17.183 [main] INFO com.vcpf.iocdemo.Test.NormalTest - 常规测试开始：
20:45:17.187 [main] INFO com.vcpf.iocdemo.hangout.hangoutway.Bike - 骑车出去逛~
```

当然，还有其他的等级 ：

* info
* debug
* warn
* error
* fatal
* off

# IoC

**IoC**的主要作用创建对象，通过控制反转将对象创建并进行反转。

在过去的项目中，对象是由开发者手动创建的。使用IoC让开发者不用再自己创建对象，可以由IoC容器根据需求自动在配置文件中依靠写好的注解扫描项目并创建对象。

- 不用IoC： 所有对象都需要自己创建
- 使用IoC： 对象不用开发者创建，交给Spring框架创建

通过两个常用的注解`@Component`,`@Autowired`，实现对象的自动创建、自动注入。

`@Component` 用对象交给Spring容器进行管理，让Spring自动创建。

`@Autowired` 自动从 Spring 容器中，找到对应的对象，直接赋值给变量

``` java
@Data
@Component
public class GlobalConfig {
    @Value("${server.port}")
    private String port;
    @Value("/")
    private String path;
    @Autowired //自动注入
    @Qualifier("dataConfig") // 查询名称
    private DataConfig dataConfig;
}
```
