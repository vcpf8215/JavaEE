# JavaBean

## 什么是JavaBean？

所谓JavaBean，是用于Java语言的一种代码规范。在SpringBoot项目中，约定大于配置。JavaBean就是一套约定俗成的规则。用通俗的话将，JavaBean是一种复合固定格式的Java类，核心作用是用来封装数据。



## 按照功能分类

- 数据 Bean
- 功能 Bean
- 工具 Bean
- 业务 Bean
- 切面 Bean

# Bean规范

## 创建一个JavaBean

```java
public class BeanClass implements Serializable {
    public String message;

    public BeanClass() {
        message = "构造方法实例化Bean";
    }

    public BeanClass(String s) {
        message = s;
    }
}
```



## Bean的书写规范

但是这个方法并不复合Bean规范，Bean的书写规范主要是一下四条：

* 公共的无参构造方法
* 所有属性私有化
* 提供公共的 getter/setter 方法
* 实现序列化接口

比如下面这个`User`对象：

```Java
@AllArgsConstructor
@NoArgsConstructor
@Data
public class User {
    private String name;
    private Integer age;
    private String gender;
}
```

# Bean工厂与静态工厂

## Bean工厂

Bean工厂，是Spring IoC容器的核心接口，通过IoC容器化实例，自动管理Bean的生命周期，包括创建、依赖注入、销毁等操作。

```Java
public class BeanInstanceFactory {
    public BeanClass createBeanClassInstance() {
        return new BeanClass("调用实例工厂方法实例化Bean");
    }
}
```



## 静态工厂

静态工厂，通过**静态**方法创建一个Bean，用创建实例的方式返回Bean对象。

```java
public class BeanStaticFactory {
    private static BeanClass beanInstance = new BeanClass("调用静态工厂方法实例化Bean");

    public static BeanClass createInstance() {
        return beanInstance;
    }
}
```

# 配置Bean

## 配置Bean的生命周期

在service包中，完成对Bean的生命周期的配置：通过注解完成对Bean的初始化和销毁(类似于C++的构造函数和析构函数)；

```java
import com.vcpf.jee202405110404.service.MyService;
import org.springframework.context.annotation.Bean;

public class BeanInitDestroyConfig {
    @Bean(initMethod = "initService", destroyMethod = "destroyService")
    public MyService getMyService() {
        return new MyService();
    }
}
```

> 这里的`initMethod`方法和`destroyMethod`方法所对应的值，需要我们提前在其他包中写好构造函数和析构函数



## 配置容器中的Bean

容器配置类，即配置组件，也是配置 Bean。是用一个 Bean 去配置另一个 Bean；

```java
@Configuration
public class JavaConfig {
    
    // 构造方法实例化
    @Bean(value = "beanClass")
    public BeanClass getBeanClass() {
        return new BeanClass();
    }

    // 静态工厂实例化
    @Bean(value = "beanStaticFactory")
    public BeanClass getBeanStaticFactory() {
        return BeanStaticFactory.createInstance();
    }

    // 实例工厂实例化
    @Bean(value = "beanInstanceFactory")
    public BeanClass getBeanInstanceFactory() {
        BeanInstanceFactory bi = new BeanInstanceFactory();
        return bi.createBeanClassInstance();

        // return new BeanInstanceFactory().createBeanClassInstance();
    }
}
```

> 通过调用 `Bean工厂` 、`构造方法` 获取容器中的Bean 



## 配置可扫描的包

将Bean交给Spring框架管理，需要告诉Spring哪些需要自动托管

```java
@Configuration
@ComponentScan("com.vcpf.jee202405110404.service")
public class ScopeConfig {
}
```

> 该类不需要过多的配置，核心作用就是通过注释的方式开启包扫描。



### 可以扫描到的包

```java
package com.vcpf.jee202405110404.service;

public class MyService {
    public void initService() {
        System.out.println(this.getClass().getName()+"执行自定义的初始化方法");
    }

    public MyService() {
        System.out.println("执行构造方法，创建对象。");
    }

    public void destroyService() {
        System.out.println(this.getClass().getName()+"执行自定义的销毁方法");
    }
}
```



## 理解 Bean 的生命周期

关键注解：`@Scope` 

​	在默认的属性下，生命周期为其内部的指定类，不写的情况下，默认就是添加注解的类名。

### 原型模式

```java
import org.springframework.context.annotation.Scope;
import org.springframework.stereotype.Service;

// 直接指定实例的使用域，这里指定是原型模式

@Service
@Scope("prototype")
public class PrototypeService {
}
```



### 单例模式

``` java
import org.springframework.stereotype.Service;

/**
 * 直接注解交给容器，使用的就是默认的单例模式
 */
@Service
public class SingletonService {
}
```



# 测试

测试类：

```java
package com.vcpf.jee202405110404.test;
import com.vcpf.jee202405110404.Bean.BeanClass;
import com.vcpf.jee202405110404.config.JavaConfig;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;


public class TestBean {

    // 直接main驱动
    public static void main(String[] args) {
       // 初始化Spring容器ApplicationContext，直接使用配置类做初始化
       // 开启容器
       AnnotationConfigApplicationContext appCon = 
          new AnnotationConfigApplicationContext(JavaConfig.class);

       // 各种方式获取bean，不同获取方式，获取的是不同的bean，注意观察它的hash码
       BeanClass b1 = (BeanClass)appCon.getBean("beanClass");
       System.out.println(b1+ b1.message);
       BeanClass b2 = (BeanClass)appCon.getBean("beanStaticFactory");
       System.out.println(b2+ b2.message);
       BeanClass b3 = (BeanClass)appCon.getBean("beanInstanceFactory");
       System.out.println(b3+ b3.message);

       // 关闭容器
       appCon.close();
    }
}
```

package com.vcpf.jee202405110404.test;
import com.vcpf.jee202405110404.config.ScopeConfig;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;
import com.vcpf.jee202405110404.service.PrototypeService;
import com.vcpf.jee202405110404.service.SingletonService;

/**
 * 测试容器中，bean的作用域
 */
public class TestScope {
    public static void main(String[] args) {

       // 初始化Spring容器ApplicationContext
       // 按配置类来初始化容器，得到容器，打开容器
       AnnotationConfigApplicationContext appCon = 
          new AnnotationConfigApplicationContext(ScopeConfig.class);

       // 获取单例模式下的bean，不论多少个，均是同一个
       SingletonService ss1 = appCon.getBean(SingletonService.class);
       SingletonService ss2 = appCon.getBean(SingletonService.class);
       System.out.println(ss1);
       System.out.println(ss2);

       // 获取原型模式下的bean，每次获取的是不一样的bean
       PrototypeService ps1 = appCon.getBean(PrototypeService.class);
       PrototypeService ps2 = appCon.getBean(PrototypeService.class);
       System.out.println(ps1);
       System.out.println(ps2);

       // 关闭容器
       appCon.close();
    }
}
